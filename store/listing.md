# Google Play 商店資訊（草稿）

上架時直接複製貼到 Play Console →「商店資訊」。語言：中文（台灣）zh-TW。

## App 名稱（最多 30 字）

```
省回來 - 買貴了就省回來
```

## 簡短說明（最多 80 字）

```
買了覺得太貴？設成回本目標，每天少花一點記一筆，看著進度一點一點省回來。
```

## 完整說明（最多 4000 字）

```
買了一件覺得有點貴的外套？換了新手機心裡有點痛？
「省回來」幫你把這筆錢一點一點省回來。

【怎麼用】
1. 把買太貴的東西加成「回本目標」，例如 3,000 元的外套
2. 今天少喝一杯飲料、自己帶便當，就記一筆「省下多少」
3. 看著進度條往前跑，直到完全回本 🎉

【功能】
• 多個回本目標，一筆省錢可以分給好幾個目標
• 預計回本日：依照最近的省錢速度幫你估算
• 統計：每天、每週省多少，最常因為什麼省下來，連續幾天有省錢
• 快捷原因：常用的省錢理由一點就填好
• 每日提醒：在你設定的時間提醒你記一筆
• 桌面小工具與快捷選單：不用打開 App 也能快速記一筆
• 刪錯了可以馬上復原
• 備份與還原：匯出成檔案，自己保管
• 多裝置同步（選用）：用你自己的 Google 帳號，在多支手機間同步

【重視隱私】
• 資料只存在你的手機裡，沒有廣告、沒有追蹤
• 開啟同步時，資料存在你自己的 Google 雲端硬碟的 App 專用資料夾，開發者看不到
• 不需要註冊帳號

【開放原始碼】
程式碼公開在 GitHub：github.com/corgi8cm/SafeMoney
```
